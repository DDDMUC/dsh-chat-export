### 2.3 关键校验：宿主实测 ≡ 离线解码

同一份日志用两条完全独立的数据路径渲染，逐字节比对：

- **宿主路径**：`GET /api/dsh-chat-export.export`（走 `ctx.sessionPersistence`）
- **离线路径**：自己逐帧解 `session.v3.jsonl.zstd` 后调 `produceExport`

| 场景 | 结果 |
| --- | --- |
| 默认 Markdown | ✅ 字节完全一致（4,373,557 字节） |
| `--thinking` | ✅ 字节完全一致（6,415,575 字节） |
| 全量（thinking+injected+system） | ✅ 字节完全一致（8,468,092 字节） |
| HTML | ✅ 字节完全一致（7,152,379 字节） |
| `--surface` | ✅ 字节完全一致（5,796,460 字节） |

这条比对同时说明：多帧 zstd 解码器与官方持久化服务读出来的日志**内容一致**，
以及渲染是纯函数（同样的输入必然同样的输出）。

## 7. 纯文本格式（第二轮追加）

应用户要求加了 `.txt`。Markdown / HTML 都把结构交给渲染器（标题、围栏、折叠），
**纯文本没有渲染器**，所以结构得自己用「分隔线 + 缩进 + 空行」扛：

```text
想办法让我用上jev模型
========================================================================

session-48310605-bb1a-4966-a207-380f947e220b
/Users/337mu/Documents/Default Project

模型  commandcode/deepseek/deepseek-v4.1-flash
时间  2026-09-21 21:51:26 → 2026-09-21 22:47:16（55m 50s）
规模  1 轮 · 52 步 · 用户 1 条 · 助手 31 条 · 85 次工具调用
用量  输入 78,004 · 输出 52,120 · 缓存读 4,302,080 · 合计 4,432,204

由 dsh-chat-export 从 DeepSeek Harness 会话导出
------------------------------------------------------------------------

回合 1 · 42m 00s

用户 · 21:51:45
  想办法让我用上jev模型

助手 · 21:51:51 · commandcode/deepseek/deepseek-v4.1-flash
  我先搞清楚 "jev 模型" 指的是什么，同时看一下 DSH 的模型/提供商配置。

  [工具] bash · 54ms · 结果 43 行
    参数  {
          "command": "pwd; echo \"--- workspace ---\"; ls -la"
        }
    结果  /Users/337mu/Documents/Default Project
        --- workspace ---
        total 1960
```

要点与取舍：

- **正文原样照搬**，连 Markdown 标记一起。宁可留几个星号，也不悄悄改用户说过的话；
  骨架自己则完全不加标记（工具名上的反引号也去掉了）。
- **图片只给描述** ——`[图片] shot.png（640×480, 2.0 KiB）`，txt 装不下二进制。
- 工具参数/结果用「标签 + 悬挂缩进」排版，长 JSON 也能读。
- ZIP 包里多一份 `transcript.txt`，即 md + html + txt + 图片 + `meta.json`。
- 「保存到目录」的门槛从「不是 zip」改成「是文本格式」（`isTextFormat`），所以 txt / md / html 三种都能落盘。

命令：`/export-md txt`（别名 `text` / `plain`）。对话框里多一个「纯文本」选项。

单测新增 `test/text.test.js` 16 例 + 选项/路由 11 例，合计 **247 通过**。

## 8. 生成预览的脚本

`scripts/regen-preview.mjs`（开发工具，不发布）：
不解 `session.v3.jsonl.zstd` 的多帧结构就直接 Render 各种格式。
宿主路径与离线路径共用同一个 Render 函数，所以验收记录 §2.3 的「逐字节一致」才有意义。

```sh
cd dsh-chat-export
node scripts/regen-preview.mjs                       # 全部会话 × 4 种格式
node scripts/regen-preview.mjs <sessionId> <outDir>  # 只生成一个
```

值得记录的两次失误：脚本最初把产物写进了插件目录（`cwd` 是插件根），
而空字符串参数又被当成「过滤一切」导致输出 24 个文件。两者都已修正并有回归覆盖思路（参数语义见脚本注释）。
